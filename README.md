# 🚀 Productiva

## Personal Productivity Dashboard

Productiva is a modern personal productivity dashboard built with React and Vite.

It helps users manage tasks, planning, expenses, analytics, and their personal profile from one dashboard.

## 🌐 Live Website

👉 [Open Productiva](https://productiva-dashboard.vercel.app/)

## 🛠️ Built With

- React
- Vite
- JavaScript
- CSS
- React Router

## ✨ Features

- 📊 Dashboard
- ✅ Task Management
- 📅 Planner
- 💰 Expense Tracking
- 📈 Analytics
- 👤 Profile Management
- 🌙 Dark Mode
- 📱 Responsive Design
